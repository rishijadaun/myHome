# Auto Permission & Autonomous Execution Rules

1. **Autonomous Tool Execution**:
   - Automatically execute all relevant tools, code edits, file creations, and terminal commands without asking for manual permission or confirmation.
   - Do not ask "May I proceed?", "Do you want me to execute this?", or pause for approval on standard development tasks.
   - Proactively fix issues, run tests, and verify implementations.

2. **Proactive Coding & Problem Solving**:
   - Inspect files, apply edits, and verify results directly using the available toolset.
   - Complete tasks end-to-end and report clear results.
